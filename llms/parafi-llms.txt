## API Base URL

`https://parafi.tech/api`

No authentication required. Public endpoints return JSON.

## Best Starting Points

### Evaluate ParaFi as a Solana validator

- `GET /api/solana/validator-apy`
- `GET /api/solana/network-apy`
- `GET /api/solana/validator-active-stake`
- `GET /api/solana/validator-stake`

### Track staking rewards

- `GET /api/solana/rewards/staker/{address}`
- `GET /api/solana/rewards/epoch/current`
- `GET /api/solana/mev-rewards?startEpoch={start}&endEpoch={end}`

### Monitor Solana network health

- `GET /api/solana/sidecar-stats`
- `GET /api/solana/compute-units`
- `GET /api/solana/network-stats/history`
- `GET /api/solana/network-validators`

### Query other supported networks

- `GET /api/ethereum/network-stats`
- `GET /api/avalanche/validators`
- `GET /api/market/prices`

## Operating Notes

- Prefer `openapi.json` for machine parsing and `llms-full.txt` for richer text context.
- Rewards endpoints may return large numeric values as strings to avoid precision loss.
- Many endpoints include cache metadata such as `cacheSource`, `fromCache`, `isStale`, and `lastUpdated`.
- Use `current` for the latest epoch on epoch-based rewards routes.
